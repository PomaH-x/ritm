# Ритм — личный план (этапы 1–6)

Веб-приложение + PWA для ежедневного планирования и учёта по сферам жизни.

## Что уже работает

- Недельная сетка 09:00–01:00 (настраивается), шаг перетаскивания 15 мин.
- События: создание выделением диапазона, перенос между днями, растягивание за нижний край,
  редактирование, копия на завтра, удаление с отменой, отметка «сделано» кружком.
- Сферы со своими цветами, нормами (часы или разы в неделю), типом нагрузки и быстрыми названиями.
- Нормы недели: сделано / стоит в плане / цель.
- Подсказки при выделении свободного времени: предлагаются сферы с отставанием от нормы,
  выполненные нормы не предлагаются, учитываются правила плана (лёгкий вечер Пн/Ср/Пт после 21:30,
  цифровой закат, воскресенье — день отдыха, длина слота, одна тренировка в день).
- Шаблон рабочей недели (заполнен по скриншоту календаря), копирование прошлой недели.
- Тёмная и светлая тема, телефон (вид по дням), установка как приложение, работа без интернета.
- Резервная копия в JSON и загрузка с объединением по свежести записей.

На телефоне: касание пустого места — подсказки на час; долгое нажатие и протяжка — выбрать диапазон
или перенести событие.

## Этап 2: страница «День»

- Разделы по образцу ежедневного отчёта: сон, спорт, питание, работа, ЕГЭ, шахматы,
  цифровая гигиена, финансы, гигиена, состояние, плюс ближайшие задачи из плана.
- Всё сохраняется само через полсекунды после правки; можно листать дни назад.
- Часы сна считаются по времени «лёг/встал», минуты ЕГЭ и шахмат — из сделанных событий
  в расписании, часы работы — из рабочих занятий. Ручной ввод перекрывает подсчёт.
- «Как вчера» копирует вчерашние значения раздела, пока сегодняшний пуст.
- Спорт: тренировка дня по программе, подходы, ежедневный минимум. Цель растёт на шаг в неделю,
  если на прошлой неделе хотя бы раз все подходы сделаны по цели; на потолке — предложение усложнить.
  Программа редактируется.
- Финансы: итоги за 30 дней, текущий месяц или выбранный период.
- Свои поля в любом разделе (⚙) и свои разделы; встроенные поля и разделы можно скрыть.

## Этап 3: отчёты

- Страница «Отчёты»: день и неделя. Один и тот же объект отчёта показывается на экране,
  уходит в PDF и (на этапе 5) нейросети. Формат — JSON с русскими подписями и единицами,
  чтобы модель понимала его без пояснений.
- Отклонения от плана и то, что получилось, считает код по правилам из PDF-плана
  (сон, отбой, телефон, вода, белок, фастфуд, лимиты, тренировки, тактика, 20% и т. д.).
  В недельном отчёте — нормы, средние, повторяющиеся срывы и таблица по дням.
- Чек-ин недели (оценка, что получилось, что мешало, проекты, что улучшить) — входит в отчёт.
- PDF собирается в браузере (pdfmake, грузится только по кнопке); на телефоне открывается «Поделиться».
- Тренировки: четверг и воскресенье — одна тренировка на улице; в дни без тренировки — ежедневный минимум.
  Тренировки, отмеченные на странице «День», засчитываются в недельную норму спорта.

## Этап 4: публикация и синхронизация

Пошаговая настройка — в `SETUP.md`.

- Синхронизация через скрытую папку приложения на Google Диске (доступ только к ней — `drive.appdata`).
  Сервера нет: телефон и компьютер обмениваются одним файлом, слияние по каждой записи —
  «побеждает более свежая правка», удаления мягкие.
- Второе устройство при первом подключении предлагает взять данные с Диска, чтобы стартовые
  сферы и занятия не задвоились.
- Автосинхронизация при открытии, через 15 секунд после правок, при возвращении в приложение
  и при появлении сети — пока действует часовой доступ Google; потом одно нажатие на кнопку.
- Перенос данных текстом (Настройки → Синхронизация) — для данных из предпросмотра.

## Этап 5: отчёты для чата DeepSeek

- Нейросети внутри приложения нет. Кнопка «Скопировать и открыть чат» (страница «День» и «Отчёты»)
  собирает текстовый отчёт за день или неделю, копирует его и открывает твой чат на chat.deepseek.com.
- Шаблоны — `src/lib/template.ts`. Отклонения размечает код: [серьёзно] — грубое нарушение правила плана
  или повтор 2+ раза за неделю, [мелочь] — единичный небольшой промах; число повторов — прямо в строке.
- Заметки из «Состояния» и чек-ина передаются только если заполнены.
- Настройки → «Чат с DeepSeek»: ссылка на чат и разовая инструкция (тон, формат, выдержка из плана —
  `src/coach/plan.ts`).

## Этап 6: прогресс

- Страница «Прогресс» с периодами 7 дней / 30 дней / всё время: сон и время отбоя, нормы
  (по дням за 7 дней, по неделям для длинных периодов), рост целей и факт по упражнениям,
  доходы и расходы (по месяцам за всё время, с целью 200 тыс.). Графики — собственный SVG без библиотек.

## Правки после запуска

- Шаблонов больше нет: у события есть «Повторять» (каждые N недель по выбранным дням, всегда или до даты),
  как в Яндекс-Календаре. Повторения создаются автоматически; изменить или удалить можно «только это»
  или «это и следующие». Разово превратить события недели в повторяющиеся — меню ⋯ на странице «Неделя».
- Отметки «сделано» убраны: прошедшее событие считается сделанным; не сделал — удали его.
- Пробные варианты ЕГЭ (тестовый балл и задания с ошибками) в карточке ЕГЭ, график на «Прогрессе»,
  в отчётах для DeepSeek — баллы, средний за 4 недели и частые ошибки.
- Раз в неделю — резервная копия в видимую папку «Ритм — резервные копии» на Google Диске (последние 8).
- Курсор-указатель и шрифт карточек как в Яндекс-Календаре, полосы прокрутки скрыты.

## Ученики и дань АМ

- Раздел «Ученики» (вместо «Отчётов»): ученики центра и мои, добавление, правка, архив, объединение тёзок.
- «Найти учеников в расписании»: имена из названий занятий в сферах «Офлайн» (центр) и «Онлайн» (мои),
  у каждого ученика может быть своё время — тогда общее занятие делится на отдельные с даты начала учёта.
- Настройки → «Ученики и деньги»: ставка за час и тарифы центра, каждая версия с датой «действуют с».
- Формат занятия центра (групповое/индивидуальное) — у каждого занятия: групповое, если в это время
  занимается ещё кто-то из учеников центра.
- Отчёты для DeepSeek и PDF (день и неделя) — внизу страницы «День». Чек-ин недели убран.
- Новые таблицы (students, subs, marks, payments, premiums) — в копиях и синхронизации, старые не тронуты.
- Расписание: на прошедших занятиях с учениками значок ₽ — красный, если кто-то не оплатил (разовое,
  моё занятие или неоплаченный абонемент), зелёный — если всё оплачено. Нажатие открывает лист занятия:
  «Оплатил», «Не оплачено», отмена (у учеников центра — с причиной для отчёта), «Вернуть занятие»,
  «Оформить абонемент с этого занятия», дата получения денег. «Изменить занятие» — прежний редактор.
- Абонементы: 4 или 8 занятий, срок 30 дней (для 8 — 30 или 60), продажа задним числом, оплачен / не оплачен,
  продление срока. Покрывает прошедшие неотменённые занятия ученика в свой срок по порядку.
- Мои ученики: баланс = пополнения и оплаты минус стоимость прошедших занятий (ставка × часы), минус — долг.
- «От АМ» → «Отчёт для центра»: неделя, дань за разовые, комиссия за абонементы (по неделе продажи),
  премия (вычитается из дани своей недели), отмены; «Подготовить отчёт» — текст в точном формате.
- Финансы → «Доход» считается сам по дате получения денег: центр — цена минус дань, абонемент — твоя доля
  в день оплаты, мои — вся сумма. Число, введённое вручную, важнее.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, с телефона — по адресу из консоли (та же Wi-Fi сеть)
npm run build        # сборка PWA в dist/
npm run preview      # проверить сборку локально
npm run build:single # один HTML-файл без service worker (для быстрого показа)
```

Установка на телефон как приложения и офлайн работают только по HTTPS. Бесплатно — через GitHub Pages:
в проекте уже есть `.github/workflows/deploy.yml`. Создай репозиторий, загрузи туда проект, в
Settings → Pages выбери Source: GitHub Actions. Через пару минут приложение будет доступно по адресу
`https://<логин>.github.io/<репозиторий>/`. На Android открой его в Chrome → меню → «Установить приложение».
Данные при этом хранятся на устройстве, а не на GitHub.

## Структура

```
src/
  types.ts              модель данных
  db.ts                 IndexedDB (Dexie), первый запуск, шаблон недели, бэкап
  lib/time.ts           даты; логический день заканчивается в 04:00
  lib/recommend.ts      правила подсказок
  lib/stats.ts          прогресс по нормам
  components/           сетка, окна, нормы
  pages/                Неделя, Сферы, Настройки
```

## Заделы под следующие этапы

У каждой записи есть `id` (UUID), `updatedAt` и `deleted` (удаление мягкое). Этого достаточно для
синхронизации по принципу «побеждает более свежая правка»: сервер будет хранить те же записи,
а клиент — отправлять изменённые после последней синхронизации и забирать чужие.
